A FEW THINGS TO KNOW

Before you dive in.

Will scanning change my files?

The scanner reads file metadata. It does not delete or reorganize your files. Cleanup is a separate action you choose. Scan results themselves are saved to the application’s data folder.

Do I need administrator access?

Normal scans run without administrator access. Protected or inaccessible locations are reported, so a partial scan is distinguishable from a complete one.

Is “on disk” the space I can recover?

Not necessarily. Allocation, shared hardlinks, cloud files, and filesystem metadata can affect the result. Moving something to the Recycle Bin may not free its space immediately. DiskSizer explains unknown allocation instead of treating it as certain.

How do saved scans work?

Results save automatically and are retained until you remove them. You can export a copy or reopen a dated, read-only scan. Rescan for current metadata or before deleting files. Previews show the file currently at the saved path.

Which systems does DiskSizer support?

The current download is for Windows 10 and Windows 11 on x64. It is a ZIP distribution: extract all its files together before running DiskSizer.exe. Find build instructions and source in the GitHub repository.
