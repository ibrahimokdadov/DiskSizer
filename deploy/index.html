Features

Everything to understand
your storage at a glance

⌕

Find the files that matter

Search all scanned files by name, type, or modification age. Sort by logical size or on-disk allocation and open any containing folder.

◉

See the bigger picture

Explore your storage in a largest-first list, treemap, or sunburst. Drill into folders while smaller map entries remain available in the list.

▷

Preview before cleanup

Select a file to inspect its details and supported media previews. Open it in Explorer and review it before choosing to recycle it.

◈

Understand on-disk sizes

See logical size and measured allocation, with shared hardlinks counted once in folder totals. Unknown values stay visible; allocation is not a promise of reclaimable space.

↓

Return to a saved scan

Scans save automatically. Export a copy or reopen a dated, read-only result. Rescan when you need current information or want to delete files.

◷

Stay in control

Follow live counts and stop a scan when needed. Partial results and inaccessible folders are identified so you can see what was covered.

A local measurement, with limits

Version 1.1.0 scanned a development dependency folder with 14,950 files and 1,895 directories in 2.197, 2.188, and 2.100 seconds on our Windows test machine. These repeated runs did not control cold-cache conditions.

The timings include allocation metadata and saved indexing, and exclude drive discovery and final UI rendering. They are not a whole-drive estimate or a comparison with other disk analyzers.

Saved indexing keeps file records out of the JavaScript heap, but uses additional disk space and write time. Scan speed depends on your drive, file count, permissions, and cache state.

Getting started

Your storage,
in three steps

1. Open DiskSizer

Download the Windows x64 ZIP, extract the entire archive, and run DiskSizer.exe. This build is unsigned.

2. Choose a location

Select a drive or folder. Normal scans need no administrator access; inaccessible locations are reported.

3. Explore and review

Find large files, inspect previews, and save a copy of your scan. Saved scans occupy disk space until you remove them.
